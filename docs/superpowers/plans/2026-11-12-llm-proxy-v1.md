# llm-proxy v1 implementation plan

Goal: a local Rust proxy allowing Claude Code to use Codex through multiple
ChatGPT subscription accounts, keeping the current account until its quota is
exhausted and then trying the next account.

Architecture: one Cargo package with Anthropic ingress, account routing/storage,
and a separate Codex backend/translation boundary. Tokio, Axum, reqwest/rustls,
Serde, Clap, tracing; Rust edition 2024. No agent tool execution in the proxy.

## Tasks

1. CLI, TOML configuration, atomic private storage and browser/device OAuth.
   Identify accounts by user and workspace; refresh once per account; allow
   account changes while serving without losing concurrent updates.
2. Anthropic Messages compatibility: text, tools/results, base64 images including
   tool results, reasoning summaries, structured output, HTTP SSE/non-streaming,
   WebSearch, local token estimates and portable Claude Code compaction.
3. AccountPool: stable insertion order, persisted active account and quota reset,
   HTTP/SSE quota classification, bounded A → B → C failover, 60-second fallback
   cooldown without a known reset, 429 when all exhausted, 503 with no valid login.
4. Safe continuation: account/model authenticated reasoning envelopes; never
   replay another account's encrypted reasoning. No previous_response_id or native
   server compaction. No automatic replay after content or ambiguous network errors.
   Cancel on disconnect, bounded buffers/timeouts, heartbeat, graceful shutdown,
   metadata-only logging.
5. HTTP routes, README/config examples, full automated verification and a real
   Claude Code session when credentials/client are available.

## Interfaces

CLI (updated naming convention): `accounts login --name NAME
[--login-method browser|device-code]`, `accounts list [--output-format table|json]`,
`accounts remove ACCOUNT_ID`, `serve [--default-model MODEL] [--listen-port PORT]`;
global `--state-dir`, env `LLM_PROXY_STATE_DIR`.

HTTP: POST /v1/messages, POST /v1/messages/count_tokens, GET /v1/models,
GET /health. Bind only 127.0.0.1:18765 by default. Claude Code's incoming token
is never forwarded upstream. TOML model aliases and default model, with CLI
default-model override. Unknown model IDs produce a clear error.

State defaults to $XDG_STATE_HOME/llm-proxy or ~/.local/state/llm-proxy.
Directories 0700, credentials 0600; separate per-account credentials; atomic
replacement and cross-process synchronization. Changes apply to subsequent
requests, existing requests finish with their leased account.

## Review focus and acceptance

- Distinct users in one workspace must not be merged; re-login must not duplicate.
- Login/remove/refresh races must not resurrect deleted accounts or lose tokens.
- Generic 429, access-denied models, network and 5xx failures are not hard quota.
- A quota error may arrive in HTTP 200 SSE before or after output.
- Cross-account/model reasoning cannot replay; stream failure cannot duplicate tools.
- Test fragmented UTF-8/SSE, interleaved tools, stop reasons, images, search,
  structured output, compaction, hot account changes, resets and concurrency.
- Run cargo fmt --check; cargo clippy --all-targets --all-features --locked --
  -D warnings; cargo test --locked; cargo build --release --locked.
- Live acceptance: Claude Code reads/edits files, runs tests, invokes a subagent,
  views an image, searches and compacts. Simulate quota instead of exhausting it.
