# V1 delivery scope

Local CLI-managed proxy connecting Claude Code's Anthropic Messages requests to
Codex subscription accounts. Architecture and ownership are defined in
[architecture](../../architecture.md); setup belongs in the [README](../../../README.md).

## Requirements

- Browser/device OAuth, refresh, private atomic storage and cross-process coordination.
- Distinct user/workspace identity; safe login/remove/refresh races and hot account changes.
- Sticky insertion-ordered accounts; confirmed-quota failover, reset windows and bounded
  attempts. All exhausted returns rate limit; no valid account returns 503.
- Text, function tools/results, base64 images, reasoning summaries, structured output,
  streaming/buffered Messages, WebSearch, token estimates and portable compaction.
- Verified account/generation/model reasoning identity; preserve portable history across
  failover. Never replay emitted output or uncertain upstream work.
- Disconnect cancellation, bounded resources, graceful shutdown and metadata-only logs.
- Proxy translates requests/events; Claude Code executes tools and owns the agent loop.

## Interfaces

CLI exposes `accounts login/list/remove` and `serve`, with global `--state-dir` /
`LLM_PROXY_STATE_DIR`. TOML config controls provider/model aliases and listener settings.
HTTP exposes `/v1/messages`, `/v1/messages/count_tokens`, `/v1/models` and `/health`.
Keep native listeners and host port publication on loopback; keep credentials private.
