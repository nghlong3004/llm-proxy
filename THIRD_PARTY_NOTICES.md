# Third-party references

## claude-code-proxy

Source: https://github.com/raine/claude-code-proxy
Reference snapshot inspected: `main`, package version `0.1.48`, 2026-11-12.
The GitHub commit page available during the investigation resolved `main` to
`2e2975a`; raw source pages were independently cached, so this is a reference
revision, not a claim that all independently retrieved files share that revision.
A fresh local clone used to cross-check native protocol/naming on 2026-11-12
resolved to `fe107180f7a69c6d63dd4421a6567cf641c1f103`.
No upstream source tree is vendored or fetched during builds.

Our independently organized OAuth, Codex HTTP headers, Responses lane/request
mapping, SSE reduction, reasoning replay, token estimates and hosted-search
implementation use the native protocol behavior and examples in this project.
The upstream license is retained here for adapted material.

`src/providers/codex/schema.rs` ports the schema-pattern walker and strict-schema
normalizer directly from `providers/codex/translate/request.rs` at `fe107180`.
`tests/fixtures/codex/raine-contract.json` was generated by running the pinned
reference translator/header builder with synthetic input and credentials.
The fixture exporter is retained beside it; reference code is not a build/runtime
dependency. See that directory's README for reproduction and intended differences.
